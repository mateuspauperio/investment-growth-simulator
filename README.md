# Carteira-de-investimentos
Planilha: planejamento de investimentos em Fundos Imobiliários (FIIs), permitindo definir valores de aporte, prazo, taxa de rendimento e perfil de risco. Com base nesses dados, são simulados cenários de crescimento do patrimônio e dividendos, além da distribuição do investimento por tipo de FII, promovendo organização e diversificação da carteira.
